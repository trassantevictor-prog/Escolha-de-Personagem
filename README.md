# Escolha de Personagens

Projeto de estudo feito com **HTML, CSS e JavaScript**.

O usuário escolhe um personagem clicando nos avatares ou envia uma selfie, e uma IA (Puter.js) transforma a foto em um personagem de videogame.

**Demo:** https://trassantevictor-prog.github.io/Escolha-de-Personagem/

## Tecnologias
- HTML5
- CSS3 (Flexbox, posicionamento, unidades `vh`)
- JavaScript (DOM, funções, eventos, `async/await`)
- [Puter.js](https://developer.puter.com/) para gerar a imagem com IA
- Git e GitHub Pages

## O que pratiquei
- Layout com Flexbox e `position: absolute`
- Seleção e alteração de elementos com `querySelector`
- Leitura de arquivo com `FileReader`
- Chamada assíncrona a uma API de IA, com tratamento de erro

## Observação
O projeto está em **modo teste** (`MODO_TESTE = true` no `scripts.js`), que mostra uma imagem de exemplo. Para gerar o personagem de verdade, mude para `false`. Nesse caso, a geração usa a conta Puter de quem está usando e precisa de saldo.
